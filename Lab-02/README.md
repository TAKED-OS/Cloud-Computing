## Задание 11. Проверка nginx

На исходном учебном EC2 выполнил `sudo nginx -t`. Команда завершилась с кодом 0.

```text
nginx: the configuration file /etc/nginx/nginx.conf syntax is ok
nginx: configuration file /etc/nginx/nginx.conf test is successful
```

Результат сохранён как текстовый вывод SSH. По завершении проверки EC2 остановлен. AWS подтвердил, что правила группы безопасности и параметры тома совпали с исходными.

## Задание 13. Длительность простоя

При исходном эксперименте длительность простоя не замерял. В основном отчёте сохранены HTTP 500 и восстановление после отката. Чтобы измерить простой, надо зафиксировать время первого неуспешного запроса и первого успешного запроса после восстановления.
